DAGGER CADDIE PERSONAL PWA — STARTER v0.1
1. Create a free GitHub account at github.com.
2. Create a new PUBLIC repository named dagger-caddie. Never upload sensitive personal data, API keys, or private range files.
3. On the repository page choose Add file > Upload files and upload index.html, profile.json, manifest.json and icon.svg (not the zip). Commit the upload.
4. Settings > Pages > Build and deployment > Deploy from a branch > main > /(root) > Save.
5. Open https://YOUR-GITHUB-USERNAME.github.io/dagger-caddie/ in Safari after the Pages deployment completes.
6. Safari Share > Add to Home Screen > Open as Web App > Add.
7. Enter distances manually initially, choose lie, and tap GET DAGGER'S CALL.
8. Upload future CSV range exports in Update your range data. Tap Back up data afterward.
9. To use GPS, choose course and hole; provide VERIFIED green-center latitude and longitude, save, and tap USE PHONE GPS. There are no course coordinates preloaded: GPS will not magically recognize holes. This is deliberate.
CAVEATS:
This is a self-contained early prototype, not a finished nationwide golf GPS service. It recommends clubs using provisional sample averages; it cannot automatically recognize course/holes or see hazards. Current GPS uses green center only. No reliable sub-110-yard club calibration yet. Personal range data remain on-device in browser storage unless you export them. Hosting code in GitHub public repo is publicly visible. Updating data in one browser does not synchronize across devices. Keep backup exports.
