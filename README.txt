DAGGER CADDIE V0.2 — MANUAL DISTANCES UPDATE

Upload the five app files to the ROOT of your existing GitHub repository dagger-caddie, replacing the existing files, then commit. You can also edit ONLY index.html in the GitHub repository and replace it with this new index.html; the other four files have not changed.

When Github Pages finishes deploying, reload the live website. Your previous locally saved profile stays on your iPhone. My club distances supports adding clubs, manual carry overrides, resetting an override, and an empty-bag option for friends.

IMPORTANT: Public visitors still see the October 16 starter profile unless they tap Start with an empty bag. Their own changes save to their own device, not to yours. There is no cross-device sync.
